# Proyecto Web

Para abrir la pagina en el puerto 3000 siga las siguientes instrucciones: 

- Clonar el repositorio:   git clone https://github.com/fvsjxsee/GroceryQuick-POS.git
- Instalar dependencias: npm install
- Iniciar el servidor: npm start
- Abrir en el navegador: http://localhost:3000
